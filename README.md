# 🏨 BookMyStay - Hotel Booking Website

BookMyStay is a full-stack Hotel Booking web application built with the MERN Stack (MongoDB, Express.js, React.js, Node.js). It allows users to browse hotels, view room details, make bookings, and manage reservations. The admin panel enables complete hotel and room management with secure authentication and Cloudinary image uploads.

## 💻 Installation

Clone the repository

```bash
git clone https://github.com/aqsahameedai/BookMyStay-Hotel-Booking-Website.git
```

Install dependencies

```bash
cd frontend
npm install

cd ../backend
npm install
```

Run Backend

```bash
npm start
```

Run Frontend

```bash
npm run dev
```
